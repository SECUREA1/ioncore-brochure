What counts as an “Alert”?

Alerts are raised from live telemetry + node health.
Examples raised by the suite: - EMG over threshold - EEG spike over threshold - Node silent longer than timeout - Overlay stream flooding (DoS / runaway loop) - Share link disconnected - Command queued too long (offline) You can extend with: - custom rules per nodeId - safety zones - geofence / job-site constraints

Security & Deployment Notes

Production checklist: - Use TLS (wss://) for all sockets. - Authenticate connectors (JWT / mutual TLS). - Validate telemetry schemas server-side before forwarding to operators. - Keep command channels separated from telemetry channels. - Rate-limit overlay streams (prevent flood). - Enforce RBAC: operator / supervisor / admin. - For WebRTC share: use a secured signaling service; manual copy/paste is demo-safe but not ergonomic. Branding: - Host logo and CSS in your assets pipeline. - Provide per-customer config via JSON manifest.
